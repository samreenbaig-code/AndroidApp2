# AndroidApp2 – Tim Hortons Ordering App

This is my Android version of the Tim Hortons ordering app from iOSApp2.

Features:
- Welcome screen with background image and buttons:
  - Start Ordering
  - View Saved Orders
- Order screen:
  - Coffee cup image
  - Size selector (Small, Medium, Large)
  - Cream, 2% Milk, Sugar with + / - counters
  - Notes field
  - “Add to Order” button to save an order
- Saved Orders screen:
  - Shows all saved orders with size + cream/milk/sugar counts and notes
